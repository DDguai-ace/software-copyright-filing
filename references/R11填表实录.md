# R11 在线填表实录（示例：2026-06-10 提交，XX 设备控制软件 V1.0）

以一次完整跑通的流程为例，记录**每一步点击与命令**。下次接同类任务照着走，只换字段值。文中软件名、日期、著作权人信息均为示例，实际以用户提供的材料为准。

## 一、起手式

```bash
"/c/Program Files (x86)/Microsoft/Edge/Application/msedge.exe" \
  --remote-debugging-port=9222 \
  --user-data-dir="$TEMP/edge-cdp-filing" \
  --no-first-run --no-default-browser-check "https://www.ccopyright.com/" >/dev/null 2>&1 &

curl -s http://127.0.0.1:9222/json/version      # 有 JSON = 端口活着

AB="$(npm root -g)/agent-browser/bin/agent-browser.js"
node "$AB" connect 9222                          # {"success":true}
node "$AB" set viewport 1440 900
```

> 视口一定要 1440×900。默认 900 宽时右侧「登录」被挤出可视区，`click` 会点空。

## 二、登录（人机分界点）

1. `snapshot -i | grep 登录` → 拿到 `link "登录"` 的 ref
2. `click <ref>` → **新开标签页** `register.ccopyright.com.cn/login.html`
3. 此时账号密码可能已被浏览器自动填充（`textbox` 的 value 能看到账号与掩码密码）
4. `click` 「立即登录」→ **弹出滑块拼图验证码**
5. 截图发给用户：「窗口已在你桌面打开，密码已填好，请拖滑块」
6. 用户过验证后 `get url` → 变成 `registration.html#/index` 即登录成功

**不要**试图脚本解滑块。也**不要**在验证码弹窗状态下反复点登录。

## 四、五步表单

### 第 1 步 选择办理身份
点「我是申请人」（含「我为自己创作的软件申请著作权登记」的那张卡）→ `#/application`

### 第 2 步 软件申请信息

| 字段 | 操作 | 本次值（示例） |
|---|---|---|
| 权利取得方式 | 默认已选，不动 | 原始取得 |
| 软件全称 | `fill` | XX 设备控制软件 |
| 软件简称 | **留空，不填** | — |
| 版本号 | `fill` | V1.0 |
| 权利范围 | 默认已选，不动 | 全部权利 |

填完 `get value` 逐个复核 → `click` 下一步。

> 注意：这一步点「下一步」有时需要先 `scrollintoview` 再点，否则点在可视区外无效。

### 第 3 步 软件开发信息

| 字段 | 操作 | 本次值（示例） |
|---|---|---|
| 软件分类 | 点占位文字展开，只有「应用软件 / 嵌入式软件」 | 应用软件 |
| 软件说明 | 默认已选 | 原创 |
| 开发方式 | 默认已选 | 单独开发 |
| 开发完成日期 | 见下方日期控件写法 | 2026-04-11 |
| 发表状态 | 平台默认「未发表」，**是否改动由用户定** | 未发表 |
| 著作权人 | 由账号带出，**disabled，不要改** | 示例科技有限公司 / 中国·某省·某市 / 企业法人 / 统一社会信用代码证书 / 91XXXXXXXXXXXXXXX |

**日期控件写法**（`fill` 无效，input 是 readonly）：

```bash
node "$AB" click <日期 textbox 的 ref>        # 打开面板
node "$AB" eval "(()=>{const t=[...document.querySelectorAll('.datepicker-main td')]
  .find(x=>x.textContent.trim()==='11'&&x.className.trim()==='');t.click();return 'ok'})()"
node "$AB" get value <ref>                    # 应回显 2026-04-11
```

面板默认停在当前年月，跨月/跨年要先点面板顶部的年月下拉。

### 第 4 步 软件功能与特点

六个环境字段（各 ≤50 字）直接 `fill`，然后：

- **编程语言**：`click` ref 无效，checkbox 是隐藏的。要
  `eval "(()=>{const i=[...document.querySelectorAll('input[type=checkbox]')].find(x=>(x.closest('label')||x.parentElement).textContent.trim()==='Java');(i.closest('label')||i.parentElement).click();return i.checked})()"`
  默认只显示部分语言，需先点「展开更多」才看得到 Java。
- **源程序量**：填总行数，示例 2904
- **开发目的**（≤50）：解决设备缺少远程入口、现场配置需反复切换网络的问题，实现扫码绑定与一键配网
- **面向领域/行业**（≤50）：工业设备与设施运维领域，面向值班人员与运维工程师
- **软件的主要功能**（500–1300）：示例 611 字，装全部业务与技术细节
- **软件的技术特点**（≤100）：示例 53 字，只写最突出的三四个机制

**上传**（页面上共 3 个 `input[type=file].hdUpload-imgBtn`）：

```bash
node "$AB" eval "(()=>{const fs=[...document.querySelectorAll('input[type=file]')];
  fs.forEach((f,i)=>f.id='__upfile'+i);return fs.length})()"
node "$AB" upload "#__upfile0" "…/02_源程序/源程序鉴别材料_V1.0.pdf"
node "$AB" eval "…赋 id 再来一次…"      # DOM 重渲染后 id 会丢，每次重赋
node "$AB" upload "#__upfile1" "…/03_说明书/软件设计说明书_V1.0.pdf"
```

上传成功的判据是缩略图出现，**不是** `input.files`（组件会清空）。

### 第 5 步 确认信息

只读汇总页。逐段核对：软件创作信息 → 软件权属信息 → 软件功能与特点 → 其他相关证明文件 → 提交材料清单 → 收件地址。

**提交材料清单会自动识别 PDF 页数**，示例显示「程序鉴别材料 46 页 / 文档鉴别材料 12 页」，与文件实际页数一致，可当作上传正确性的校验。

## 五、常见的失败（按出现顺序）

| 现象 | 原因 | 解法 |
|---|---|---|
| `agent-browser --version` 报 MODULE_NOT_FOUND，路径变成 `e:\c\Users\...` | Git Bash 把 shim 路径转坏了 | 直接 `node <全局>/bin/agent-browser.js` |
| 直接 `open register.ccopyright.com.cn` 回 403 | 缺 Referer | 从首页点「登录」新开标签 |
| `click 登录` 无反应 | 视口 900 宽，元素在屏幕外 | `set viewport 1440 900` |
| `fill` 日期框后 value 仍为空 | input readonly | 用 JS 点 `.datepicker-main td` |
| `click` 编程语言 checkbox 后 `is checked` = false | input 被视觉隐藏 | 点 `label.hd-checkbox-button` |
| `upload` 报 "Node is not a file input element" | 选的容器 div 不是 input | 先 eval 给 file input 赋 id 再 upload |
| `upload "… >> nth=0"` 报 "Object id doesn't reference a Node" | 不支持 nth 语法 | 同上，用 id |
| 第 2 步「下一步」点了没反应 | 按钮在视口外 | `scrollintoview` 后再点 |
