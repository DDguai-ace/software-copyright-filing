# R11 表单字段填写对照表

> 对应中国版权保护中心 R11「计算机软件著作权登记申请」，2026-03-15 新版申请表。
> 标注「默认」的字段按本技能的通用口径填，用户另有要求时以用户为准。

## 一、软件基本信息

| 字段 | 填法 | 备注 |
|---|---|---|
| 软件全称 | 全填，如「XX 设备管理软件」 | 不含版本号；不含「最/第一/国家级」；与三份材料页眉一字不差 |
| 软件简称 | **留空** | 通用既定做法 |
| 版本号 | `V1.0` | 材料中「V1.0」与「1.0」不能混用 |
| 软件分类 | 按产品形态选 | 配套硬件多为嵌入式软件，上位机/管理端多为应用软件 |
| 软件作品说明 | 填「**原创**」 | 若是升级版，选「修改」并填原登记号、附原证书 |
| 开发完成日期 | **申请日往前 60–70 天，同批各件错开**（如 60/65/68/62 天） | 不得两件同日；必须 ≤ 首次发表日期 |
| 发表状态 | **未发表**（默认） | 已上架/已交付 → 已发表 + 首次发表日期 + 地点（城市） |
| 开发方式 | **单独开发** | 合作/委托/下达任务须提交对应权属证明 |

## 二、著作权人

| 字段 | 单位 | 个人 |
|---|---|---|
| 名称 | 营业执照全称，与公章一致 | 身份证姓名 |
| 类别 | 法人 / 非法人组织 | 自然人 |
| 证件类型 | 统一社会信用代码 | 居民身份证 |
| 证件号码 | 18 位统一社会信用代码 | 18 位身份证号 |
| 国籍/省市 | 中国 / 省·市（按营业执照地址） | 同 |

## 三、权利说明

| 字段 | 填法 |
|---|---|
| 权利取得方式 | **原始取得**（受让/继承/承受才选继受取得，需证明） |
| 权利范围 | **全部权利**（部分权利须注明具体权项） |
| 原登记号 | 仅升级/变更版本时填 |

## 四、鉴别材料

选 **一般交存**：
- 源程序：前 30 页 + 后 30 页（不足 60 页全交）
- 文档：前 30 页 + 后 30 页（不足 60 页全交）
- 均上传 PDF

例外交存只在涉密、含目标程序等特殊情形使用，需另附说明，不默认走。

## 五、技术环境（每项 ≤50 字，写中文，不堆英文参数）

**同一批多件时，这六项最容易露馅**：全部一字不差就是"批量套模板"的直接证据。按项目类型分别取值，运行硬件必须逐件不同。

| 字段 | PC 上位机 | 嵌入式设备端 | Android 移动端 |
|---|---|---|---|
| 开发的硬件环境 | 台式机 i5-10400、16GB 内存、512GB 硬盘 | 台式机 + 目标开发板与串口调试器 | 台式机 i5、16GB 内存，配真机联调 |
| 运行的硬件环境 | 通用 PC（Windows 7/10/11），USB 转串口接设备 | 目标 MCU 模组、采集传感器、小尺寸屏、I2S 功放 | Android 手机或平板，需后置摄像头与 WiFi |
| 开发该软件的操作系统 | Windows 10 64 位 | Windows 10 64 位 | Windows 10 64 位 |
| 软件开发环境/开发工具 | Python 3、tkinter、PyInstaller | VS Code、esptool、MicroPython 工具链 | Android SDK、命令行构建工具 |
| 该软件的运行平台/操作系统 | Windows 7 / 10 / 11 | MicroPython 固件（ESP32-S3），无 OS | Android 8.0（API 26）及以上 |
| 软件运行支撑环境/支持软件 | Python 运行时（打包版单文件，无需另装） | MicroPython 标准库与机器模块，无第三方运行库 | 内置 ZXing core 解码库，无其他运行库 |
| 编程语言 | Python | Python（MicroPython） | Java |
| 源程序量 | 按实际统计行数填写，不虚报 | 同左 | 同左 |

写法纪律：
- 开发硬件确实同一台机器时可以相同，但**不要整段照抄**，按用途取舍（加"开发板""真机联调""虚拟机"等限定）
- 运行硬件、开发工具、运行平台**必须逐件不同**，这三项由技术栈决定，不可能相同
- 不得虚构不存在的设备；宁可在真实基础上改措辞，也不要编造服务器型号

## 八、签章页（2026 新规，最容易废件的地方）

| 要求 | 细节 |
|---|---|
| 谁签 | **经办人本人** —— 申请人（机构）指定办理本次登记的人，不是代理机构联系人 |
| 怎么写 | **黑色中性笔亲笔手抄**承诺段落，严禁打印、代签、涂改 |
| 还填什么 | 经办人本人签名 + 身份证号码 |
| 盖章 | 单位申请加盖公章；个人申请本人签字或盖名章 |
| 承诺内容 | 独立开发、未使用 AI 开发编写代码/撰写文档/生成申请材料、信息真实、愿承担失信后果 |
| 上传 | 扫描或拍照为 PDF |

## 九、证书领取

## 个人申请额外材料

- 身份证正反面扫描件
- **《非职务开发保证书》**（本人出具）或《非职务开发证明》（单位出具），官网可下载模板
- 前提：软件不属于职务开发。职务开发（本职工作/公司任务/用公司资源）著作权归单位，个人不能登记。

## 技术环境字段的差异化要求（防批量痕迹）

同一批次多件申请，**6 个环境字段不能整段复制**。审查关注「同一申请人短期内集中申报、材料高度雷同」，字段雷同比材料雷同更容易被看出来。

- **开发的硬件环境**：按项目类型写真实差异
  - 嵌入式/设备端：台式机 + 目标开发板 + 下载调试线，例「i5-10400 台式机、16GB 内存，配 XX 开发板与 USB 下载线」
  - PC 上位机：台式机 + USB 转串口适配器 + 被测样机，例「i5-10400 台式机、16GB 内存，配 USB 转串口适配器与样机」
  - 云端/Web：台式机 + 浏览器与抓包工具，例「i5-10400 台式机、16GB 内存，配主流浏览器与抓包工具」
- **运行的硬件环境**：必须写该软件真正运行的载体（设备主控型号 / PC / 服务器），不能都写「通用 PC」
- **开发操作系统**：可写「Windows 10 64 位」「Windows 10 专业版 64 位」「Windows 11 64 位」，按实际开发机写，同批不要三件一模一样
- **开发工具**：写真实的 SDK / 框架 / 打包工具组合，不同项目自然不同
- **支撑软件**：写运行时依赖，无依赖就写「无第三方运行库」
- 每项仍须 **≤50 字**，且与该项目的说明书、源码对得上，不为了差异化编造不存在的工具
